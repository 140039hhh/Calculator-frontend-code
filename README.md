# Calculator Frontend —— 计算器前端（前后端分离作业）

## 项目简介

本仓库为「前后端分离计算器系统」的**前端部分**。负责用户界面展示、表达式输入、按钮交互，
以及通过 HTTP API 把表达式发送给后端计算并展示结果。

> 对应后端仓库见配套的 Backend 仓库（本目录的 `backend/` 在合并运行版工程中）。

## 技术栈

- 原生 HTML5 + CSS3 + JavaScript（无框架、无构建工具）
- 界面采用深色标准计算器布局（5 列按键 + 表达式输入框 + 历史面板）

## 运行环境

- 任意现代浏览器（Chrome / Edge / Firefox）
- 需要后端服务提供 `/api/*` 接口

## 安装与启动

本前端不依赖任何包管理器，直接由后端服务托管或任意静态服务器托管即可：

```bash
# 方式一：由后端服务托管（推荐，前后端同源，见后端仓库）
# 方式二：任意静态服务器
npx serve .
```

## 与后端的连接方式

前端通过 `fetch` 调用**相对路径** `/api/*`，因此要求与后端同源部署
（或反向代理把 `/api` 转发到后端）。

主要接口：

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/calculate` | 计算表达式 `{ "expression": "(1+2)*3" }` |
| POST | `/api/unary` | 一元运算 `{ "expression": "9", "op": "sqrt" }` |
| POST | `/api/percent` | 百分号 `{ "expression": "100" }` |
| GET | `/api/history` | 查询计算历史 |
| DELETE | `/api/history/{id}` | 删除指定历史记录 |

**设计约束**：前端不进行任何数学计算，所有结果均由后端返回；
停掉后端服务后，前端无法独立获得新的计算结果。

## 功能一览

- 基本四则运算（+ − × ÷）
- 复合表达式（优先级、括号、一元正负号、小数）
- 一元运算（√ ∛x x² 1/x +/−）
- 百分号
- 计算历史（后端数据库持久化，含时间，可删除/清空）
- 键盘快捷键（数字、运算符、括号、Enter、Backspace、Esc）
